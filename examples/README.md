# Examples

Usage and composition examples for the imported agents. These are **not**
agents themselves — the real agents live in `agents/`.

- [`security-audit-example.md`](security-audit-example.md) — run a security
  audit with the `security-auditor` subagent.
- [`fullstack-build-example.md`](fullstack-build-example.md) — coordinate
  backend and frontend subagents to build a feature.

See `workflows/` for reusable multi-agent orchestration definitions and
`docs/importing.md` for how agents are produced.
